# EDI - NextGen Education

NextGen Education is a modern, interactive engineering and electronics learning platform featuring simulated labs, component hubs, capstone engineering projects, real-time quizzes, and student progress tracking backed by Firebase Firestore.

## Project Structure

```text
EDI - NextGen Education/
├── Backend/       # Backend APIs and server-side services
├── Database/      # Database schemas, migrations, and Firestore scripts
├── Design/        # UI/UX wireframes, architecture diagrams, and schematics
├── Documents/     # Project documentation, SRS, and engineering specs
├── Frontend/      # React 19 + Vite web application with Tailwind/CSS styling
├── Images/        # Media assets, component imagery, and lab photos
├── Reports/       # Academic evaluation, project audits, and test reports
└── Videos/        # Demonstration videos and multimedia guides
```

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Running Frontend
```bash
cd Frontend
npm install
npm run dev
```

### Running Tests
```bash
cd Frontend
npm test
```
